# GTO Score Master

Веб-калькулятор результатов и генератор официальных протоколов ВФСК ГТО. Client-side SPA на React + TypeScript, работающая полностью в браузере без бэкенда.

## Возможности

- Создание карточки соревнования: название, дата, место, судейская бригада, набор дисциплин многоборья (20 испытаний ВФСК ГТО).
- Быстрый ввод результатов: десктопная таблица с закреплённой первой колонкой, навигация `Tab` / `Enter` / стрелками, мобильный карточный режим.
- Мгновенный расчёт баллов по 100-балльной шкале с цветовой индикацией уровней знака, автоматическое ранжирование.
- Автосохранение в `localStorage` (Zustand + persist), экспорт/импорт проекта в `.gto.json` (валидация через Zod), выгрузка CSV.
- Генерация официального PDF-протокола (A4, альбомная ориентация, встроенный кириллический шрифт Roboto, предпросмотр и скачивание).
- Редактор нормативных таблиц: ступени I–XVIII, пол, пороги «Результат → Баллы», пороги знаков отличия, сброс к официальным таблицам, экспорт/импорт нормативов.

## Запуск

```bash
npm install
npm run dev        # локальная разработка
npm run build      # продакшн-сборка
npm run preview    # предпросмотр сборки
npm run lint       # Biome
npm run typecheck  # TypeScript
```

## Тесты утилит

```bash
npm run test:score   # проверка алгоритма расчёта баллов и ранжирования
npm run test:pdf     # проверка генерации PDF со встроенным шрифтом
```

## Публикация на GitHub Pages

Сборка работает с относительными путями (`base: './'`). После пуша в ветку `main` GitHub Actions
(`.github/workflows/deploy.yml`) соберёт проект и опубликует его в Pages (ветка `gh-pages` через
официальный артефактный механизм).

## Структура

```
src/
├── data/        # справочник дисциплин и официальные 100-балльные таблицы
├── store/       # Zustand-хранилища (соревнование, нормативы)
├── utils/       # расчёт баллов, файловый обмен, генератор PDF, форматтеры
├── components/  # common, layout, competition, table, pdf, settings, participants
└── styles/      # дизайн-токены и глобальные стили (CSS-first, CSS Modules)
```
